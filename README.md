# PictureTalk Android

> 本项目为 PictureTalk 的 Android 版本，[iOS 版本](https://github.com/nowszhao/PictureTalk)

PictureTalk（图语）是一款场景化英语学习应用：拍照或从相册选图创建场景，AI 识别图中单词并标注位置，生成场景例句与中文翻译。

[![Kotlin](https://img.shields.io/badge/Kotlin-1.9.0-purple.svg)](https://kotlinlang.org)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://www.android.com)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 功能

- **场景化学习** — 拍照/选图创建场景，AI 识别单词并标注位置，生成例句与中文翻译
- **智能分析** — 按初级/中级/高级推荐单词，提供音标、释义与发音（支持自动播放）
- **学习管理** — 任务列表与搜索、单词卡片位置自定义、场景分享
- **其他** — 图片裁剪编辑、KIMI AI 配置、深色/浅色主题

## 系统要求

Android 7.0（API 24）+ · 摄像头（拍照）· 网络连接

## 安装

从 [GitHub Releases](https://github.com/nowszhao/PictureTalk4Android/releases/latest) 下载最新 APK，允许安装未知来源应用后安装即可。首次使用需在 App 内填入 KIMI API Key（从 [Kimi 开放平台](https://platform.moonshot.cn/) 获取）。

## 权限说明

- 相机：拍照创建场景
- 存储：保存与访问图片
- 网络：AI 分析与在线功能
